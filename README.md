### Abstract
**Compact Wordle** is a handheld game console device fit for any individual to play when they're bored, but also test their vocabulary and brain on the go! It features a user navigation system capturing input response from tactile buttons and set debouncing (for scrolling functionalities).

### Components List
To make this project possible, several components are required to create this console:
- x1 Arduino Mega 2560 R3
- x5 tactile push buttons
- x1 U8G2 128x64 ST7920 LCD
  - x1 220-ohm resistor
- x19 Male pin headers

### Installed libraries
Besides getting the components, the following libraries are used:
- U8g2 library (best for the ST7920 LCD) or "U8g2lib.h" specifically
